# T258 — Cannot construct a sealed bounded collection outside its module

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T258`

Bounded collections (`BoundedVec_i64_8`, …) are construction-sealed: a direct record literal in user code could forge the length invariant (`{ len: 99 }`) that makes them safe. Build and mutate them only through their `new()` / `push` / `pop` / `get` / … API.
