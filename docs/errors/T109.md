# T109 — Cross-ring return error must be `ErrorCode`

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T109`

Functions returning `Result` across ring boundaries must use `ErrorCode` (a `u32`). Use rich error types only within a single ring.
