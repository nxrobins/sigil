# T265 — Array pattern length cannot match fixed-size array

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T265`

PR P5: this array pattern can never match the scrutinee's fixed-size array `[T; N]`. A pattern with no `..rest` must have exactly `N` elements; a `[…, ..rest]` pattern's fixed prefix must have at most `N` elements. Adjust the element count to match `N`, or add/remove a `..rest` tail. (A slice `&[T]` has a runtime length, so any element count is accepted there.)
