# T218 — Cross-field refinement self-references the same field

- **Category:** Parser
- **doc_url:** `sigil://errors/T218`

Wall 4 Step 4's `where <lhs> <op> <rhs>` requires LHS and RHS to be DIFFERENT field names. `where a == a` is vacuously true (any value equals itself); `where a < a` is vacuously false. Such a predicate carries no information beyond what the record's other invariants already provide. Pick distinct fields, use a literal RHS (`where a < 100`), or drop the clause.
