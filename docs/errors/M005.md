# M005 — Module declares both `tool_main` and `entry actor`

- **Category:** ModuleSet
- **doc_url:** `sigil://errors/M005`

A module must target one execution model: `pub fn tool_main` (ephemeral forge — fresh store per call) OR `entry actor` (persistent actor — long-lived store with supervision). These ABIs are mutually exclusive. Remove one or split into two modules.
