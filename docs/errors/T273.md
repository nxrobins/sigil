# T273 — `mint` site does not hold the minting authority

- **Category:** Capability
- **doc_url:** `sigil://errors/T273`

Capabilities-as-values: `mint <Cap>` requires the minting authority capability to be in scope as an immutable borrow. Take a `&cap <Authority>` parameter (matching the cap type's `mintable_by` policy) and ensure it is in scope at the mint site. You need a capability to grant a capability.
