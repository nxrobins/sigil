# N012 — Module-name case collision

- **Category:** NameResolution
- **doc_url:** `sigil://errors/N012`

Two modules differ only in case (e.g. `fs` and `Fs`). This is rejected because some platforms treat them as the same name. Rename one to be unambiguously distinct.
