# M001 — Filename does not match first module declaration

- **Category:** ModuleSet
- **doc_url:** `sigil://errors/M001`

In project mode, each `.sigil` file must declare its first module with a name matching the filename stem. Rename either the file (`<name>.sigil`) or the leading `module <name>;` declaration so they agree. Inline `module foo { ... }` blocks declared AFTER the first module are unconstrained.
