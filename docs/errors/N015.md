# N015 — Duplicate capability authority

- **Category:** NameResolution
- **doc_url:** `sigil://errors/N015`

Two authorities within the same `cap type` declaration share a name. Authorities map to distinct bit positions in the authority mask, so a duplicate inflates the authority count (consuming the 32-authority budget) and corrupts `restrict`/mask accounting — the second occurrence is unreachable. Rename one or remove the duplicate.
