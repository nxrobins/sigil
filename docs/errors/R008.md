# R008 — Outer-ring `extern` requires `#[trusted]`

- **Category:** Ring
- **doc_url:** `sigil://errors/R008`

Declaring an `extern` binds a host function, and only a `#[trusted]` module may do that. Add `#[trusted]` after the module's `#[ring(outer)]`, or call the host function through a trusted module's non-generic wrapper instead, such as the stdlib `fs` module; calling such a wrapper needs only the outer ring. Generic code may call an `extern` only when every module governing its instance is `#[trusted]`, which can include the module that calls it.
