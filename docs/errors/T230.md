# T230 — Method `self`-param type-args don't mirror impl block's type parameters

- **Category:** Parser
- **doc_url:** `sigil://errors/T230`

SIGIL Complete v0 / Phase 6: per N6-V0, a method declared inside `impl TypeName<T, E> { ... }` must have its `self` parameter typed as exactly `TypeName<T, E>` in the same declaration order. Swapping or substituting (`self: Result<E, T>` when impl is `Result<T, E>`) silently mis-binds substitutions at dispatch time. To fix: align the `self`-param's type-args with the impl block's type parameters in declaration order.
