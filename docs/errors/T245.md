# T245 — Type does not satisfy a trait bound

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T245`

A type parameter is constrained by a trait (e.g. `<T: Hash>`), but the concrete type it was instantiated with has no impl of that trait. v1 provides built-in impls of `Hash` and `Eq` for the primitives `i64`, `str`, and `bool`; a user `record` satisfies a trait by declaring the trait's method(s) with the exact signature (structural satisfaction). To fix: instantiate with a type that has an impl, give the type the required method, or drop the bound.
