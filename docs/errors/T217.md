# T217 — Refinement RHS `.length()` references a non-array field

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T217`

Wall 4 Step 5 admits `<field>.length()` at refinement RHS position ONLY when `<field>` is directly-owned `Type::Array { elem, size }`. Slices, references to arrays, and any other type are out of scope (anti-goal A11). Use the array's exact size as a literal (`where len == 8`) instead, or convert the slice/reference to an owned array field.
