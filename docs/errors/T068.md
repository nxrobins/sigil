# T068 — Control-flow statement in `handle`/`region` body

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T068`

`handle` and `region` bodies are lowered inline within a single AIR basic block, so block-creating statements (`if`, `while`, `match`, `for`, `return`) cannot live there without a separate proof framework for cross-block effect/region scoping. Use straight-line code (`let`, `=`, expression statements). Extract control flow into a helper function called from the body.
