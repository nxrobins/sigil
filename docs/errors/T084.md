# T084 — Variant pattern against non-enum scrutinee

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T084`

Enum variant patterns (`Some(x)`, `Err(e)`) only match enum-typed scrutinees. Match a different shape, or change the scrutinee.
