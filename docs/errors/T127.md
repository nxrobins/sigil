# T127 — Closure cannot capture actor state

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T127`

A closure is a lambda-lifted function with no access to the actor's state pointer, so state is unreachable inside its body. Read a data field into a local before the closure, or borrow a capability with `grant(&field, …)` (whose closure receives a `&Cap` parameter) instead of capturing the field.
