# T264 — Array pattern requires an array or slice scrutinee

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T264`

PR P5: an array/slice destructuring pattern `[a, b, ..rest]` can only match a scrutinee whose type is an array `[T; N]` or a slice `&[T]`. Match the actual scrutinee type instead — for an enum use a variant pattern (`Variant(x)`), for a scalar use a literal/range/binding pattern, for a tuple use `let (a, b) = …` destructuring. Array patterns bind fixed positions by index and an optional `..rest` tail as a `&[T]` slice.
