# T025 — Secret-dependent memory address (CT006)

- **Category:** Effect
- **doc_url:** `sigil://errors/T025`

`load8`/`store8` at a `@SecretCT` pointer is rejected — the access pattern is observable via cache state. Use a `@Public` base address and bitwise-mask the loaded data instead.
