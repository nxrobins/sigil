# T248 — Unknown trait in a type-parameter bound

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T248`

A type-parameter bound (e.g. `<T: Foo>`) names `Foo`, but no trait named `Foo` is declared or imported in this scope. Declare it (`trait Foo { … }`) or `use` the module that does. The built-in traits are `Hash` and `Eq`.
