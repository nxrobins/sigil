# E007 — Wrong argument count in `perform`

- **Category:** Effect
- **doc_url:** `sigil://errors/E007`

`perform E.op(...)` passes the wrong number of arguments for the operation's declared arity. Match the call to the operation signature `fn op(...)` in the effect declaration. (Also fires when a `handle` clause's binder count does not match the operation's arity.)
