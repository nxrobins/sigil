# T020 — Secret-dependent branch (CT001)

- **Category:** Effect
- **doc_url:** `sigil://errors/T020`

Replace the `if` on `@SecretCT` data with a branch-free `ct_select(cond, then_val, else_val)`. The spec rejects this because the branch's wall-clock timing leaks which arm was taken.
