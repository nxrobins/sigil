# T191 — `Slot<T>` requires T to be a capability type

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T191`

Slot is a built-in linear container designed for capability accumulation. Instantiate with a `cap type` declared in scope (e.g., `Slot<Fuel>`), not a primitive or record.
