# T199 — Parametric capability literal is past the build-time deadline

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T199`

The cap-type literal declares a deadline earlier than the value supplied via `--build-deadline`, OR a `restrict_deadline(D')` argument narrows past the build deadline. The compiler refuses to build a program whose caps would be stale at compile time. Either widen the literal to a value `>=` the build deadline, raise the build deadline (or drop the flag), or remove the narrowing if it's intentional staleness for testing.
