# P028 — Malformed state-kinded type-parameter binder

- **Category:** Parser
- **doc_url:** `sigil://errors/P028`

Typestate: a state-kinded type parameter is written `<@S>` — a bare `@`-prefixed name with NO `:` bound or kind annotation. Remove the `: …` after `@S` (state markers are declared in a `state Name { … }` item, not as bounds), or drop the `@` if you meant an ordinary type parameter.
