# R810 — Certificate file unreadable, not a regular file, or over 1 MB

- **Category:** Internal
- **doc_url:** `sigil://errors/R810`

The `--cert <path>` argument must point at a regular file no larger than 1 MB. Check the path is correct, the file isn't a fifo / symlink to a special device, and re-emit if the cert was corrupted: `sigil check <source> --cert <path>`.
