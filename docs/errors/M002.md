# M002 — Duplicate module name across project

- **Category:** ModuleSet
- **doc_url:** `sigil://errors/M002`

Module names must be unique across the whole project, whether declared as top-level `module foo;` or as inline `module foo { ... }` in another file. Rename one of the colliding modules, or merge their items into a single declaration.
