# N014 — Duplicate enum variant

- **Category:** NameResolution
- **doc_url:** `sigil://errors/N014`

Two variants within the same `enum` declaration share a name. Variant tags are assigned by source order, so a duplicate name silently collides on construction and pattern-matching (the second is unreachable). Rename one or remove the duplicate.
