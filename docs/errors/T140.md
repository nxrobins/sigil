# T140 — Array element type mismatch

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T140`

All elements of an array literal share the element type inferred from element 0. Three concrete fix paths: (1) cast the offending element with `<expr> as <expected>` (the message names the expected type), (2) change element 0 to match the rest, or (3) annotate the binding with the desired element type and cast as needed (e.g., `let xs: [i64] = [1 as i64, 2, 3];`).
