# T254 — Escape of a region-allocated value

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T254`

A value heap-allocated inside a `region {}` block may not outlive the region: its memory is reclaimed when the block exits, so any surviving alias would dangle. The value cannot be the region's result, `return`ed, passed as a non-receiver argument, stored in a longer-lived record/place, or assigned to an outer binding. Copy a scalar out, or move the work that needs the value inside the region. (A region value MAY be read/mutated in place via the allowlisted stdlib collection methods — `v.push(x)`, `v.get(i)` — within the block.)
