# T257 — Private `str_from_raw` called outside module `string`

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T257`

`str_from_raw(ptr, len)` forges a `str` fat-pointer from raw memory — a wrong `len` would mint an out-of-bounds view that the `byte_at`/`substr` bounds-checks then trust — so it is stdlib-private to `string.sigil`. Build owned strings with `concat`/`join`/`itoa`, which allocate and fill the buffer for you.
