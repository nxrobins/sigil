# C005 — SMT query outside the decidable fragment (internal)

- **Category:** Capability
- **doc_url:** `sigil://errors/C005`

The runtime fragment guard rejected a solver query (quantifier, disallowed op/sort, uninterpreted function, off-width bitvector, mixed theories, or oversized formula). Every query is compiler-constructed, so this indicates a compiler bug — please report it. The program is conservatively rejected, never accepted unverified.
