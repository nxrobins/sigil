# T275 — Typestate value stored in an aggregate

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T275`

Typestate (ST-6): a typestate value is affine — storing it in a record field, enum payload, array, or generic aggregate would let you extract it twice and defeat the use-after-transition guarantee (the same smuggling channel T183/T184/T186/T242 close for capabilities). Pass the value by name through function arguments / return values instead of stashing it in an aggregate.
