# T031 — `declassify` rejects `@SecretCT` input (CT017)

- **Category:** Effect
- **doc_url:** `sigil://errors/T031`

`declassify(value, cap)` lowers `@Secret → @Public`. To go from `@SecretCT` to `@Public`, use the two-step ladder: `let mid: T @Secret = declassify_ct(value, ct_cap); return declassify(mid, pub_cap);` — each step consumes its own linear capability.
