# T184 — Enum variant payload cannot be capability-typed

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T184`

Capabilities cannot be carried by enum variant payloads. Pattern-destructure bindings (e.g., `Variant(c) => ...`) produce a fresh cap that Z3's authority tracker treats as full authority — the same aggregate-smuggling channel T183 closes for records. Pass the cap by name through actor messages or function arguments, or replace the payload with a non-cap surrogate (e.g., an i64 amount) and dispatch on a separate cap held in actor state.
