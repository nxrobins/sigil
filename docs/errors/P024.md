# P024 — `@in` must name a `Region` parameter

- **Category:** Parser
- **doc_url:** `sigil://errors/P024`

`@in r` declares the region a value lives in; `r` must be a `Region` parameter of the same function, e.g. `fn f(r: Region, v: Vec<T> @in r)`.
