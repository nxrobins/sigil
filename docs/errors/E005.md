# E005 — Unknown effect operation in `perform`

- **Category:** Effect
- **doc_url:** `sigil://errors/E005`

`perform E.op(...)` names an operation `op` that the effect `E` does not declare. Check the operation name against `effect E { fn op(...) -> ...; }`, or add the operation to the effect declaration.
