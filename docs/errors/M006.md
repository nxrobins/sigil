# M006 — Project mixes tool entry and actor entry

- **Category:** ModuleSet
- **doc_url:** `sigil://errors/M006`

Project contains both a tool entry (`pub fn tool_main` in one module) and an actor entry (`entry actor` in another). A project must target one execution model — they are run by different drivers (`execute_ephemeral` vs the actor runtime). Pick one.
