# M009 — Invalid source-file name

- **Category:** ModuleSet
- **doc_url:** `sigil://errors/M009`

Source file names must match `^[A-Za-z0-9_./\-]+\.sigil$`, contain no NUL bytes, no control characters, and no `..` path segments. Rename the file (or the path you passed) and retry.
