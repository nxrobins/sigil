# M003 — No entry point found in project

- **Category:** ModuleSet
- **doc_url:** `sigil://errors/M003`

A project must declare exactly one entry point: either `pub fn tool_main(input_ptr: i64, input_len: i64) -> i64` (forge ABI) OR `entry actor Main { ... }` (actor ABI). Add one to a module in the compilation set.
