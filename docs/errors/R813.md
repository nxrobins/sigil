# R813 — Source fingerprint mismatch

- **Category:** Internal
- **doc_url:** `sigil://errors/R813`

The cert was emitted from a different source than what's about to run. Either revert the source to the version the cert was emitted from, or re-emit the cert: `sigil check <source> --cert <path>`. The diagnostic message names the cert's hash and the freshly-computed hash; compare to find the divergence.
