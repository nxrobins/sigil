# R819 — Formal security report or CSIR fingerprint mismatch

- **Category:** Internal
- **doc_url:** `sigil://errors/R819`

Schema-v9 execution requires a formal report freshly re-derived by the current compiler. The supplied report is missing or differs in model version, checker fingerprint, canonical CSIR fingerprint, toolchain, or checked counts. Treat this as certificate tampering or toolchain drift and re-emit the certificate from the exact source and compiler binary.
