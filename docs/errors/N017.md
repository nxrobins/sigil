# N017 — Duplicate type parameter

- **Category:** NameResolution
- **doc_url:** `sigil://errors/N017`

A `fn`, `record`, or `enum` declares two type parameters with the same name (`<T, T>`). Positional substitution would silently collapse to one binding (the same reason `impl Foo<T, T>` is rejected with T229). Rename one — `<T, U>` if they are independent — or drop one if a single parameter suffices.
