# M007 — Duplicate source-file name

- **Category:** ModuleSet
- **doc_url:** `sigil://errors/M007`

Each source file passed to `compile_project` must have a unique name. Check the command line for repeated filenames, or for files passed via both a directory expansion and an explicit positional argument.
