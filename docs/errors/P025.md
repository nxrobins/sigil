# P025 — `where region(...)` must name `Region` parameters

- **Category:** Parser
- **doc_url:** `sigil://errors/P025`

`where region(a): region(b)` declares that region `a` outlives region `b`; both must be `Region` parameters of the same function, e.g. `fn f(a: Region, b: Region, ...) where region(a): region(b)`.
