# E011 — Invalid effect-row variable

- **Category:** Effect
- **doc_url:** `sigil://errors/E011`

An effect-row variable (a type parameter used inside `! { ... }`, e.g. `fn h<e>(f: Fn(i64) -> i64 ! { e }) -> i64 ! { e }`) is restricted in v1: it must be an ordinary binder on a free generic function; it must not shadow a declared effect, be used in type position, or duplicate another binder; and it may appear only in the function's declared row, the top-level row of a `Fn`-typed parameter (at most one variable per such row), or the return type. Calls to a row-polymorphic function cannot use turbofish. Rename the binder or move the row to a supported position.
