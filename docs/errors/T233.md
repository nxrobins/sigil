# T233 — Type parameter cannot be inferred at generic record construction

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T233`

PR A / SIGIL Complete: at a generic record construction site (e.g., `Holder { value: 42 }` against `record Holder<T> { value: T }`), SIGIL infers type parameters by unifying each supplied field value's type against the record's declared field types. T233 fires when the type parameter doesn't appear in any field's type — common for phantom-T records where the parameter exists only at the type level. To fix: add an explicit type annotation on the binding (`let x: RecordName<ConcreteType> = RecordName { ... }`); the annotation propagates concrete args into the construction's substitution map BEFORE field inference runs.
