# T251 — Mutation of a @ReadOnly value

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T251`

A `@ReadOnly` parameter promises the function will not mutate the value passed in, so writing through it — `p.x = …`, `p[i] = …`, or a compound assignment — is rejected. Drop the `@ReadOnly` annotation if the function legitimately needs to mutate the argument, or copy the value first.
