# T260 — `break` / `continue` outside a loop

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T260`

`break` and `continue` are loop-control statements; they are only valid inside a `while` or `for-in` loop body. Remove it, or move it into a loop.
