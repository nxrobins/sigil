# E009 — Bare `handle` on an effect with operations

- **Category:** Effect
- **doc_url:** `sigil://errors/E009`

The bare `handle E { ... }` form only widens the effect row; an effect that declares operations needs the clause form `handle <expr> { E.op(x) => ... }` so each operation has a meaning. Switch to the clause form, or remove the operations from the effect.
