# T186 — Array element cannot be capability-typed

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T186`

Capabilities cannot be the element type of an array. Indexing (`arr[i]`) produces a fresh cap binding that Z3's authority tracker treats as full authority — the same aggregate-smuggling channel T183 and T184 close for records and enum payloads. Pass each cap by name through actor messages or function arguments, or store the count as `[i64; N]` and look up the cap by index in actor state.
