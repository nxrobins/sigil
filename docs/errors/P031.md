# P031 — Effect row after a `Fn`-typed return binds to the declaration

- **Category:** Parser
- **doc_url:** `sigil://errors/P031`

In `fn f() -> Fn(T) -> U ! { E } { … }` the trailing `! { E }` is the DECLARATION's effect row (the pre-existing meaning), not the returned Fn type's latent row. To attach the row to the type, parenthesize it: `-> (Fn(T) -> U ! { E })`. This is a warning, not an error — the parse proceeds with the declaration binding.
