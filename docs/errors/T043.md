# T043 — Reassignment forbidden — value owns a linear or scope-tied resource

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T043`

Reassignment is allowed for primitives, ActorRef, arrays, and any record / enum whose fields are themselves reassignable. It is rejected when the value transitively owns a capability (linear) or a borrow (scope-tied). For cap-bearing values, consume the cap rather than store it; for borrow-bearing values, drop the borrow before reassigning.
