# C012 — `mut` actor-state field's element shape is not yet preserved across dispatches

- **Category:** Capability
- **doc_url:** `sigil://errors/C012`

A `mut` state field persists when every stored element can be promoted at its storing write: inline scalars, `str`, flat scalar records (a record of scalars), and `Vec`/`Map` collections whose elements (Vec elements, Map keys/values) are any of those. What is not yet preserved is an element the promotion's field copy cannot deep-copy — a record with a pointer-bearing interior (str/Vec/record fields), a nested collection, or a 256-bit value. Flatten the element (inline the nested fields as scalars), store parallel collections of promotable elements, or await the transitive-promotion slice of the persistent-pointer-state epic.
