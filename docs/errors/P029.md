# P029 — Inclusive range `..=` in a `for` header

- **Category:** Parser
- **doc_url:** `sigil://errors/P029`

Range-for: `for v in a..=b` is not supported — use an exclusive end (`for v in a..b`). One canonical loop form keeps the compile-time bounds fact (`v < end`) exactly the loop condition, with no off-by-one variant to mis-derive.
