# T195 — Deadline-typed capability subtype mismatch

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T195`

The source cap's deadline is earlier than the target site requires. Covariant subtyping reads `Approval(D_a) <: Approval(D_b)` iff `D_a >= D_b` — a longer-lived cap is acceptable wherever a shorter-lived one is required, but not the reverse. Widen the target's expected deadline to `<=` the source's, or narrow the source via `restrict_deadline(...)` (Stage 2/3 of the deadline rollout).
