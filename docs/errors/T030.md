# T030 — `@Internal`/`@Secret` → `@SecretCT` upcast forbidden (CT016)

- **Category:** Effect
- **doc_url:** `sigil://errors/T030`

`@SecretCT` values may only be constructed from declared `@SecretCT` parameters, `@SecretCT`-annotated literals, CT intrinsic returns, or `@Public` data (which carries no confidentiality to lose). Untrusted sources (FFI returns, declassified data) cannot be promoted.
