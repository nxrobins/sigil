# T123 — Cannot assign to actor state in a handler

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T123`

Actor state is immutable after construction: a handler may only read it. Assign the field once in `init` instead. (Handler-time mutation is a separate, future feature.)
