# T190 — Range pattern: lower bound greater than upper bound

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T190`

Inclusive range patterns require `lo <= hi`. Swap the bounds (e.g., `0x30..=0x39`, not `0x39..=0x30`).
