# T259 — `for-in` iterator has a `next` of the wrong shape

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T259`

The lean iterator protocol recognizes `for x in it` when `it`'s type has `next(self @Mut) -> Option<T>` — exactly one `@Mut self` parameter and an `Option<_>` return. Adjust `next` to that shape, or iterate an array / a `.iter()` view that yields it.
