# T075 — Intrinsic argument type mismatch

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T075`

Intrinsic arguments must be integer types: `alloc(size: i64)`, `load8(ptr: i64)`, `store8(ptr: i64, val: i64)`.
