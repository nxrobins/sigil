# P030 — `mut` on a non-state field

- **Category:** Parser
- **doc_url:** `sigil://errors/P030`

The `mut` marker is only valid on an actor `state {}` field. Record fields are immutable-by-shape: remove the `mut`. (Actor state mutability is opt-in via `mut` inside a `state {}` block.)
