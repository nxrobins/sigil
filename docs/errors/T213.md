# T213 — Refinement RHS literal out of i32 range

- **Category:** Parser
- **doc_url:** `sigil://errors/T213`

Refinement RHS integer literals must lie in the closed range [-2_147_483_648, 2_147_483_647]. The QF_LIA Z3 encoding used by Step 1 is sound only within this range; out-of-range literals could diverge from i64 runtime semantics. Choose a smaller literal, or wait for a later step that adopts a QF_BV<64> encoding.
