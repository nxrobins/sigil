# T276 — Undeclared state marker

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T276`

Typestate (ST-5): a type argument in a protocol's state position names a marker that is not in its declared set. The state space is closed at the `state Name { … }` declaration. Use one of the declared markers, or add the marker to the `state` declaration.
