# T231 — Method dispatch arity mismatch with impl block's type parameters

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T231`

SIGIL Complete v0 / Phase 6: at method dispatch, the receiver's concrete type-arg count must equal the impl block's `type_params.len()`. A receiver shaped `Result<i64>` (1 arg) cannot dispatch against `impl Result<T, E> { ... }` (2 params). To fix: supply the missing type argument(s) at the receiver's construction site, or call against a different impl block whose type-param count matches.
