# T156 — Module name shadowed by local variable

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T156`

A `use sigil::<m>;` import is shadowed by a local binding of the same name. Either rename the local, or qualify the call as `sigil::<m>::<fn>(...)` to bypass the local-name lookup.
