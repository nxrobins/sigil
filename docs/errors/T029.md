# T029 — Secret-dependent allocation size (CT015)

- **Category:** Effect
- **doc_url:** `sigil://errors/T029`

`alloc(n)` and `region(n)` with `n: @SecretCT` are rejected — allocator state and heap layout are observable. Size buffers from a `@Public` upper bound instead.
