# T221 — Pattern-narrowing or variant-refinement field-resolution conflict

- **Category:** Parser

Wall 4 Step 6 reserves T221 for two cases: (a) a `match` arm's variant-declared refinement contradicts an already-attached refinement on the matched scrutinee — refactor the upstream code so the refinements are compatible; (b) a variant `where` clause references a field name that doesn't appear in this variant's payload (cross-variant references are not in scope per N19-S6) — pick a payload field of THIS variant or move the refinement to the variant that owns the field.
