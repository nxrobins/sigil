# R009 — Messaging, spawn or capability operation in outer-ring code

- **Category:** Ring
- **doc_url:** `sigil://errors/R009`

The outer-ring module has no host import for `send`, `ask`, `spawn` or a capability operation (`.restrict()`, `.split()`, `.draw()`, `mint`), so outer-ring code cannot use them. Move the code that messages, spawns or operates on a capability into an inner-ring module. Outer-ring code is FFI surface: it cannot own a capability (R001), and no call crosses the ring boundary (R004), so it cannot reach that code by a call either.
