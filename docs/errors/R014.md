# R014 — Actor declared in an outer-ring module

- **Category:** Ring
- **doc_url:** `sigil://errors/R014`

The actor runtime hosts only the inner-ring module, so an actor declared in a `#[ring(outer)]` module could never run. Declare the actor in an inner-ring module. An outer-ring module is FFI surface: it holds functions, such as a tool's `tool_main`, and not actors.
