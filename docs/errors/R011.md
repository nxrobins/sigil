# R011 — Non-capability fuel argument

- **Category:** Capability
- **doc_url:** `sigil://errors/R011`

The fuel argument to `spawn` must be a `Fuel`-typed capability. Pass an owned `Fuel` cap (often a state field) rather than a primitive.
