# E003 — Inner-ring function declares a privilege effect

- **Category:** Effect
- **doc_url:** `sigil://errors/E003`

Inner-ring functions cannot declare `Unsafe` or `FFI` in their effect row — those are outer-ring privileges. Two concrete fix paths: (1) move the function to a `#[ring(outer)] #[trusted]` module if it genuinely needs the privilege effects, or (2) drop just `Unsafe`/`FFI` from the effect row (other effects like `Alloc` or user-declared domain effects are fine to declare in inner ring).
