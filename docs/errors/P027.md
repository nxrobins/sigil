# P027 — Malformed higher-kinded type-parameter kind

- **Category:** Parser
- **doc_url:** `sigil://errors/P027`

A higher-kinded type parameter is written `<F: * -> *>` (one argument) or `<F: * -> * -> *>` (two). The kind must be `*` separated by `->`, must have at least one `->` (a bare `*` is not higher-kinded), and may have at most two `->`. Bounds come after, e.g. `<F: * -> * + Functor>`.
