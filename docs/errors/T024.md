# T024 — Secret-dependent array index (CT005)

- **Category:** Effect
- **doc_url:** `sigil://errors/T024`

Indexing by a `@SecretCT` value leaks the index through cache state. Iterate the full array under a `@Public` counter and `ct_select` the wanted element by bitwise mask.
