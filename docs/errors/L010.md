# L010 — Source file is not valid UTF-8

- **Category:** Lexer
- **doc_url:** `sigil://errors/L010`

SIGIL source files must be valid UTF-8. The compiler validates each input file at ingest before parsing begins. Common causes: a file saved in a legacy encoding (Latin-1, Windows-1252), a binary file mistakenly passed as source, or a truncated multi-byte sequence. Save the file as UTF-8 and retry.
