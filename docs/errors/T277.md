# T277 — `mint … for <target>` target is not a resource

- **Category:** Capability
- **doc_url:** `sigil://errors/T277`

Capabilities-as-values: the `for <target>` of a `mint` names the resource the capability authorizes and must be a nominal value (a record/actor type). Capabilities, primitives, references, and tuples are not valid mint targets.
