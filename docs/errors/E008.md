# E008 — Handle does not cover the effect's operations

- **Category:** Effect
- **doc_url:** `sigil://errors/E008`

A clause-form `handle` must provide exactly one clause per operation of each effect it discharges. Add a clause for every missing operation, and remove any duplicate clause for the same operation.
