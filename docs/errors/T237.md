# T237 — Linear closure passed to non-linear `Fn(T) -> U` parameter

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T237`

HOF prerequisite / N4-HOF: a closure that captures one or more `Cap<_>` values (and is therefore `Type::Fn(_, _, true, _)` — linear, single-use) was passed where a non-linear `Fn(T) -> U` parameter is expected. The general closure-call dispatch only admits non-linear (multi-use) closures; linear closures must invoke through a `grant` block so the runtime can enforce single-use semantics. To fix: either (a) rewrite the closure to not capture the `Cap<_>` value (capture a non-cap projection if possible), or (b) invoke through `grant cap, |args| { ... }` — the existing grant-lifecycle dispatch handles linear closures safely. Note: this restriction is intentional for the prerequisite PR; a future PR may add runtime single-use tracking for general linear dispatch (AG-HOF-B documents the deferred work).
