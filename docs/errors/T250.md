# T250 — Conflicting trait impls

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T250`

The same `(trait, type)` pair is implemented by two or more explicit `impl Trait for Type` blocks. Coherence requires at most one impl of a trait for a given type — merge the blocks or delete the duplicate.
