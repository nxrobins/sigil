# E006 — Unknown effect in `perform`

- **Category:** Effect
- **doc_url:** `sigil://errors/E006`

`perform E.op(...)` names `E`, which is not a declared effect. Declare it with `effect E { fn op(...) -> ...; }`, or check the spelling.
