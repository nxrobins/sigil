# R006 — `#[trusted]` requires `#[ring(outer)]`

- **Category:** Ring
- **doc_url:** `sigil://errors/R006`

The `#[trusted]` privilege unlocks `handle Unsafe` and FFI extern declarations — it is only meaningful in the outer ring. Either change the module to `#[ring(outer)] #[trusted]`, or drop `#[trusted]` if the module does not need trust.
