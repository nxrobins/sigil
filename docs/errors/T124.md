# T124 — Actor state field assigned more than once in `init`

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T124`

Each actor state field must be assigned EXACTLY once in `init` — a second assignment to the same field is a double-init. Remove the redundant assignment (state is set once at construction, then immutable unless declared `mut`).
