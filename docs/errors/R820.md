# R820 — Certificate provenance did not validate

- **Category:** Internal
- **doc_url:** `sigil://errors/R820`

The active deployment profile requires authenticated certificate provenance, or the supplied signed envelope is malformed. Check the signer id, Ed25519 public key, deployment context, revocation list, and signature algorithm, then re-emit the certificate from a trusted signing key.
