# R001 — Outer-ring code cannot own capabilities

- **Category:** Ring
- **doc_url:** `sigil://errors/R001`

Capabilities live in the inner ring. Pass a borrowed capability via `grant(&cap, fn(ref) -> ...)` instead of taking ownership in outer-ring code.
