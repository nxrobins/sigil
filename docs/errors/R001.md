# R001 — Outer-ring code cannot own capabilities

- **Category:** Ring
- **doc_url:** `sigil://errors/R001`

Outer-ring code cannot own a capability. Keep the code that owns and uses the capability in an inner-ring module. Outer-ring code may take a borrowed `&Cap` parameter, but no call crosses the ring boundary, including one made inside a `grant` body (R004), so an inner-ring capability cannot be handed to outer-ring code.
