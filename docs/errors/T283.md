# T283 — `tool_main` is not `pub`

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T283`

Only an externally callable function is exported from the compiled module, and a free function is externally callable only when it is declared `pub`. A private `tool_main` therefore compiles to a module with no entry point, which the runtime refuses to execute (`no tool_main entry point found`). Declare it `pub fn tool_main(...)`.
