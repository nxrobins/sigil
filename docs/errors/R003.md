# R003 — Inner-ring code cannot call `extern` functions

- **Category:** Ring
- **doc_url:** `sigil://errors/R003`

Inner-ring code cannot reach FFI, directly or through another module: a call into an outer-ring wrapper is a cross-ring call (R004), including one made inside a `grant` body. Declare the calling module itself `#[ring(outer)] #[trusted]` if it is FFI surface code (outer-ring code cannot own capabilities, R001, or call inner-ring modules, R004), or keep the FFI call out of inner-ring code.
