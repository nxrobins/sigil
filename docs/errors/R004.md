# R004 — Direct cross-ring call requires a grant

- **Category:** Ring
- **doc_url:** `sigil://errors/R004`

Inner and outer rings can only interact via `grant(&cap, fn(ref) -> ...)`. Direct calls across the boundary are forbidden.
