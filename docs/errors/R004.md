# R004 — Call across the ring boundary

- **Category:** Ring
- **doc_url:** `sigil://errors/R004`

No call crosses the ring boundary, in either direction, including one made inside a `grant` body: `grant` lends a borrowed capability to a closure that runs in the caller's own ring. Declare the calling module `#[ring(outer)] #[trusted]` if it needs FFI-backed code, or call only modules in its own ring.
