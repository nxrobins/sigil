# T246 — Trait method signature mismatch

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T246`

The type has a method with the trait's name, but its signature does not match what the trait requires — check the parameter types and the return type. For `Hash` the method must be exactly `fn hash(self: Self) -> i64`; for `Eq` it must be `fn eq(self: Self, other: Self) -> bool` (with `Self` being your type). Adjust the method signature to match, or drop the bound.
