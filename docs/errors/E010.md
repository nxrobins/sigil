# E010 — Orphan `perform` of an undeclared effect

- **Category:** Effect
- **doc_url:** `sigil://errors/E010`

`perform E.op(...)` requires the effect `E` to be available. Declare it in this function's effect row (`fn f(...) ! { E } { ... }`), or wrap the computation in a `handle <expr> { E.op(x) => ... }` that discharges it.
