# T229 — Impl block declares duplicate type parameter names

- **Category:** Parser
- **doc_url:** `sigil://errors/T229`

SIGIL Complete v0 / Phase 6: an impl block's type parameter list must contain unique names — `impl Foo<T, T> { ... }` is rejected because positional substitution against the receiver's concrete type args would silently collapse to one binding. To fix: rename one of the duplicates (e.g., `impl Foo<T, U>` if the two are truly independent, or drop one if a single parameter suffices).
