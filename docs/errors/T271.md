# T271 — Type name contains `__`, reserved for monomorphization names

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T271`

R2 (HK3 hardening): a user-declared `record`/`enum`/`cap type` name may not contain `__` (double underscore). The compiler mangles a monomorphized generic instance to `Name__arg` (e.g. `Box<i64>` → `Box__i64`); a user type sharing that name would collide in the type registry, shadow the instance's fields, and crash AIR field lookup. Rename using a single underscore or camelCase (e.g. `Box_i64` or `BoxI64`).
