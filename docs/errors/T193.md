# T193 — Type name `Slot` is reserved

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T193`

`Slot` names the built-in linear container; user records, enums, and cap types cannot reuse the name. Rename your type (e.g., `SlotState`, `MySlot`).
