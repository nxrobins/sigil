# T255 — Conflicting frozen and mutable arguments alias the same object

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T255`

A call passes the same heap object as both a `@ReadOnly` (frozen) argument and a mutable argument: mutating it through the mutable handle would break the read-only view the frozen parameter promises. Pass a copy to one of the two arguments, or make both parameters `@ReadOnly`.
