# N008 — Ambiguous symbol from multiple `use` aliases

- **Category:** NameResolution
- **doc_url:** `sigil://errors/N008`

The same function name is reachable via two different `use` aliases. Disambiguate by qualifying the call site (`module::fn`) or by removing one of the conflicting `use` declarations.
