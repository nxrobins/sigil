# N016 — Duplicate protocol state

- **Category:** NameResolution
- **doc_url:** `sigil://errors/N016`

Two states within the same `state` declaration share a name. Protocol states are a closed ordered set of markers, so a duplicate is dead. Rename one or remove the duplicate.
