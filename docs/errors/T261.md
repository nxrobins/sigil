# T261 — Malformed tuple

- **Category:** TypeCheck
- **doc_url:** `sigil://errors/T261`

A tuple needs at least two elements: `(a, b)`. A 1-tuple `(a,)` is rejected — a single parenthesized value `(a)` is just that value — as is the empty `()` and a tuple over MAX_TUPLE_ARITY (12) elements. For `let (x, y) = v;` destructuring, `v` must be a tuple whose arity matches the number of names: `let (x, y) = (1, 2);` binds two names, so the value must be a 2-tuple. v1 reads a tuple ONLY via `let (..) =` destructuring — `.0`/`.1` index access and tuple match-patterns are not yet supported.
