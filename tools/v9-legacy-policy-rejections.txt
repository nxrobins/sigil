# Tools the CSIR v9 legacy-host occurrence policy refuses by design.
#
# Each of these performs a host call (fs_read / http_get) inside a branch on an
# @Internal value, typically the error code of the previous host call. Without a host
# profile every host operation's occurrence is declared Public (see
# proofs/lean/LambdaSigil/V9BoundaryContracts.lean), so the second call's occurrence
# would leak Internal control to the host and the production verifier refuses the
# program with I013 (occurrence-policy detail 40). The CI compile-sweep pins exactly
# that refusal for every path listed here, so a policy relaxation, a stale row, or an
# unrelated failure all turn the sweep red. The same rows must compile with
# `sigil check --host-profile ephemeral <tool>`: the ephemeral host declares every
# operation it links with Internal occurrence, which is the host these tools run under
# (sigil-runtime/src/ephemeral_profile.rs), so the sweep pins both verdicts.
#
